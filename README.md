## 👋 About me

I'm a software engineer from **Kigali, Rwanda**, studying at **NGA**. I build full-stack products for cooperatives, sports federations, retailers, and public services, and I care about the details that make software usable where it is actually deployed: bilingual interfaces, offline resilience, and data that can be trusted.

- 🏗️ **What I build:** multi-tenant web platforms with TypeScript, Node.js, React or Next.js, and PostgreSQL
- 🌍 **What I care about:** software that works in English *and* Kinyarwanda, on slow connections, for people without accounts
- 🧪 **How I work:** typed end to end, tested, containerised, and rehearsed for deployment before it ships
- 📚 **Currently learning:** Java, C++, embedded systems with Arduino and ESP32, and computer networking

<table>
<tr>
<td width="60%" valign="top">

### [CoopManage Rwanda](https://github.com/couper117/coopmanage-rwanda)

A cooperative management platform for Rwandan cooperatives. Staff run members, money, stock, sales, meetings, documents, and reports from one place, in **English and Kinyarwanda**. Members and farmers need no account, no smartphone, and no internet.

**Engineering highlights**

- 🔒 **Four-layer tenancy** with a route sweep that fails the build if any route can leak another cooperative's data
- 💰 **Money as decimal strings**, never floats. Void and reverse, never delete. Append-only audit trail enforced by the database
- 📶 **Offline resilience:** cached screens, saved drafts, idempotent writes so a retried submission can't double-post
- ✅ **1,384 tests** across three packages, an accessibility gate, and a gate that fails if any of the 144 endpoints lacks a passing test
- 🚢 **Rehearsed deployment** in CI on every push, from an empty database to a signed-in first cooperative
